支える文と、支えない文

ソースノートの型は、Source type、Confidence、Supports、Limitations、Best use です。決定文が支えるのは、SpaceX への通知、契約の巻き戻し、提案の 11/12、最長通知、支配権変更の窓、Astra を渡さない、ToS への自信の欠如、Twitter/X の契約違反、xAI の宣誓、約4年の提携、影響を受けるのは開発者、です。支えないのは、終了日の双方確定、Astra の仕様、Cursor の応答です。

ヘルプは運用境界でそれを伸ばします。移行期間としての 11/12。そのあいだ現在のモデルアクセスを続ける。Cursor がより早く切る可能性。公式終了日は両社確定待ち。BYOK はローカル Chat/Agent のみ。Codex 拡張は別エージェント。Tab / Auto / Cloud / CLI / API / SDK は Cursor 供給。記事自身が directional と書き、最新は Cursor 公式を見よ、ともします。

不在は、空白ではない
