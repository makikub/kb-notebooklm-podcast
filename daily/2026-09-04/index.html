1. スループットがレビューを追い越す — Critical でも理解量は増えない

地図の第一の型は、スループットがレビュー容量を超える、である。エージェントは大きな差分を速く出す。レビューが浅いままだと、リスクは入力速度から、隠れた設計負債と保守負債へ移る。Astra の発売文は、コーディング、computer use、研究、文書作成を、最初の依頼から成果物まで運ぶ、と書く。Codex では、文脈が埋まってもノートを残し、以前の窓を検索できる、と書く。長い走りが安くなる。理解の窓は、同じ速さでは広がらない。

なぜ効くか:

  • Critical は能力の段である。レビュー容量の段ではない
  • 差分が速くなるほど、浅い承認が「監督した」に聞こえる
  • ハーネスが段を増やすほど、人が触る実装が減る

今日の角:
地図は、生成塊を一度にレビューできる大きさに保て、と書く。Astra の長い走りと async tools は、塊を大きくする方向である。mid-turn steering は、途中で軌道を直せる。直せることは、見ていることを前提にする。見ていない steering は、降伏の高速化である。点数表を核にしない。追い越す速度と、残る理解を先に名指す。

対話の種:
「この差分は、一度座って読める大きさか。長い走りを、誰が途中で見ているか。」

2. 監督のパラドックス — 止まった仕事を再開する技量

地図の第二の型は、監督のパラドックスである。監督する人は、コーディングとデバッグと設計の技量が要る。エージェントを厚く使うと、手を動かす練習が減る。監督に必要な技量が削れる。今日のモニタは、そのパラドックスを、停止面に出す。公式は、モニタが正当な活動を、サイバー誤用や無許可として旗を立てうると書く。ChatGPT / Codex では、続ける前に人が見る。API では、止まる。再開は、ゴム印ではない。止まった理由を、人が再構成できなければならない。

なぜ効くか:

  • 「人がループにいる」は、人が判断できることではない
  • 防御サイバーの正当な仕事ほど、旗が立ちやすい、と公式自身が書く
  • 長く走る仕事ほど、途中の旗を読む材料が散る

今日の角:
地図は、責任あるレビューアが独立に理解できないものは、実装させるな、と書く。モニタが止めた仕事は、その試験そのものである。なぜ止まったか言えないなら、再開する資格が無い。Auto-review の拒否を迂回しない、という Astra の整列は、モデル側の話である。再開する人の整列は、残っていないことがある。

対話の種:
「止まった仕事を、会話を見ていない人が再開してよいか。止まった理由を、同じ言葉で言えるか。」

3. モニタは第二のレビュー面である — 走っているときだけが負債ではない

地図は、人間のエネルギー予算を第一級の制約にする。入力は減る。監督と検証の密度は上がる。回復を無視すると、生成が速くてもレビューが折れる。今日の安全検査は、その密度を、ベンダー側からも足す。誤整列モニタは、対応する Responses 要求で、途中を非同期に見る。警報を出し、会話を止めうる。公式は、unnecessary interruptions を減らす、と書く。減らす対象がある、ということである。

なぜ効くか:

  • レビュー容量は、差分を読む面だけではない。旗を読んで再開する面もある
  • API で止まる系と、製品面で確認を求める系は、人が入る位置が違う
  • 長時間エージェントは、旗の間隔が、人の注意力の間隔と一致しない

今日の角:
昨日の実行面は、ツールがどこで走るかだった。今日のモニタ面は、走っている仕事を、誰が止めてよいかである。同じ「ゲート」に潰さない。Daybreak は、高度なサイバーを誰に渡すかの門である。誤整列モニタは、渡したあとの軌道を見る門である。レビューアは、両方の後ろに立つ。

対話の種:
「止まっているのは誤用か。誤検知か。再開する人は、どちらの証拠を持っているか。」

4. Daybreak は門である — 一般面の Astra と混ぜない

高度なサイバーは制限される。一般面の Astra は、セキュアなコードレビューとパッチまでは防御側に使える、と書く。より進んだ作業は拒否する。Daybreak は、その先の経路である。脆弱性／PoC の検証、マルウェア分析、検知エンジニアリングへ、より緩い緩和を載せる予定である。Companion の $1B は、最前線の防御側へ助成する一行である。核にしない。門の幅である。誰が走らせてよいかと、走った結果を誰が理解できるかは、別の面である。

なぜ効くか:

  • Critical の能力と、公開の作業面は、同じ棚ではない
  • 助成はアクセスの話である。レビュー容量の話ではない
  • 「防御だからレビューは薄い」は、地図が支えない文である

今日の角:
地図のベンダー依存は、提供者固有のエージェントを既定にすると、停止と値と振る舞いが運用リスクになる、と書く。今日の Astra は、その依存の上に、モニタ停止を足す。none-effort が無く、custom temperature が無いのは、制御つまみが減った、という型である。レビュー面を、温度で誤魔化せない。Responses 必須は、ツール面の住処が一つに寄る、という型である。寄った先で止まる。

対話の種:
「これは一般面の拒否か。Daybreak の門か。止まったのはモニタか。レビューアはどの棚にいるか。」

5. 理解の負債と意図の負債 — 速く書いたコードと、止まった理由

地図は、川島の Scrapbox を借りて、理解の負債と意図の負債を分ける。コードが分かっていないのが、認知／理解の負債である。コードは分かるが、規則の理由が消えているのが、意図の負債である。エージェントは、外に出した仕様、ADR、テスト、制約、文書しか使えない。チームの暗黙の記憶は使えない。Astra が速く書くほど、理解の負債は溜まる。モニタが止めるほど、意図の負債が表に出る。なぜこの制限があるか。なぜこの作業は防御か。なぜ再開してよいか。理由が残っていないと、旗は読めない。

なぜ効くか:

  • 差分を読めることと、止まった理由を読めることは、別の理解である
  • 外に出していない「なぜ」は、モニタにもレビューアにも届かない
  • 検証税は、DORA の言い方では、採用コストそのものである。旗の誤検知も、その税に入る

今日の角:
地図は、規則の「なぜ」を ADR とドメイン制約と、意図が読めるテスト名に残せ、と書く。今日の再開面は、その「なぜ」の試験である。Path to Astra は、検査が防御サイバーや長い走りを巻き込みうると、先に書いた。発売日にそれが製品になる。理由を書いていないチームは、止まった仕事を、モデルの自信で再開する。

対話の種:
「この制限の理由は、文書にあるか。止まった軌道を、暗黙の記憶なしで説明できるか。」

6. オフロードと降伏 — steering があっても比較点は要る

地図の Osmani の枠は、有用な委任と、認知の降伏を分ける。オフロードは、人間側の比較点を残す。降伏は、モデルの枠組みと答えが、人間の答えになる。人がループに名目であることは、安全ではない。なぜかを再構成できなければならない。Astra は、途中の指示を、新しい目標にすり替えにくい、と書く。Codex では、依存しない仕事を続けながら、非同期に質問できる、と書く。比較点を残す設計である。比較点が無ければ、steering も質問も、降伏の経路になる。

なぜ効くか:

  • mid-turn steering は、見ている人のための面である
  • async tools は、人が見ていない時間を長くする
  • モデルが整列していても、人が降伏していれば、再開はゴム印である

今日の角:
地図は、自明でないエージェント出力には、先に期待を作れ、反論を求めよ、と書く。モニタが止めたあとは、その儀式が製品になる。ChatGPT / Codex の確認は、儀式の入口である。API の停止は、入口が無い。再開手順を、チームが先に書いておかなければならない。巻き戻しへの Cursor 声明は、今日も書かない。供給面の話と、レビュー容量の話を、一つにしない。

対話の種:
「steering する前に、自分の期待を一文で言えたか。止まったあとに、モデルの説明をそのまま信じていないか。」

なぜ認知負債地図が部品になるか

  • 同じ「強いモデル」でも、Critical の能力と、人が一度に読める量は、別の段である
  • 同じ「人がループにいる」でも、差分を読む面と、旗を読んで再開する面は、技量が違う
  • 同じ「ゲート」でも、Daybreak の許可と、誤整列モニタの停止は、入る位置が違う

KBの言葉では、スループットが理解を追い越し、監督技量が削れ、検証税が財務になる、という地図である。昨日の実行面は、ツールがどこで走るかだった。今日は、走っている仕事と、止まった仕事の両方を、人がまだ持てるかである。公式の型は、Critical の広配備、高度サイバーの制限、Daybreak 経路、モニタによる正当仕事の停止を一次で固定し、$1B と API の型と、未出荷の Function Hooks と、Astra 待ちの banked reset を aside に留め、昨日の実行面を一行に残し、Cursor の声明と X の取得を、空欄のまま残す。

トレードオフ

長い走りを許すと、塊がレビュー窓を超える。async を足すと、見ていない時間が増える。steering を足すと、見ていない軌道修正が増える。モニタを厚くすると、正当な防御と長い走りが止まる。薄くすると、無許可の軌道が残る。Daybreak を発売の再話にすると、門が消える。$1B を核にすると、助成がレビュー容量に見える。Function Hooks を核にすると、未出荷の拡張が主題になる。Critical の点数を核にすると、理解の負債がベンチマークになる。昨日の Self-hosted を今日の核にすると、レビュー容量が実行面の続きになる。巻き戻しの不在を声明にすると、無い文を足す。
