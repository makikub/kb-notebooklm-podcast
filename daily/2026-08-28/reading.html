The Harness Leaves GitHub — Origin Scratch and Model Hardware

ハーネスは長いあいだ、GitHub リポジトリがあることを前提にしていた。今日 Cursor は Cloud Agents からその前提を外す。Start from scratch は Origin repo とブラウザ preview と Vercel publish を、SCM 接続の前に置く。Anthropic の Model Hardware Standard は同じバスを実験台と工場へ伸ばす。新モデルではない。地図の命題は、性能がハーネスで決まる、である。

今日のテーマはハーネスの境界が伸びること

knowledge-base-llm の Agent Harness Landscape は、エージェントの性能がモデル単体ではなく、リポジトリ構造、制御、成果物、テスト、レビューループ、オーケストレーションの周辺で決まる、と書く短い地図です。五つの次元は、行動前の案内、行動後の修正、セッションをまたぐ継続、自律の制御、役割の分離です。昨日までの読み物は、デプロイゲート、制御の分類、実装前のレビュー規準、常時稼働のパターン、KB＋コードベースのオンボーディングでした。今日は分類とゲートを棚に戻し、ハーネスの境界そのものがどこまで伸びたかを見ます。

Cursor は 8/27、Cloud Agents が GitHub や他社 SCM を接続しなくても始められる、と書きました。リポジトリピッカーで Start from scratch を選び、そのままプロンプトします。裏で Origin repo が作られます。気に入ったら Create repo。名前は自分で付けるか提案から選び、可視性は private か internal。足場の付いた Origin repo が残り、Codebase タブから辿れます。クラウドエージェントの環境はブラウザへポートフォワードされ、design mode も使えます。Vercel アカウントを繋いで publish すると live URL が付きます。publish には Vercel が要ります。

Anthropic は同じ日、Model Hardware Standard の研究プレビューを開きました。AI エージェントが物理装置を安全に操作するための共有仕様です。最初の相手は科学研究ラボと先進製造。顕微鏡、分注機、ロボットアームを並列に動かし、定型の創薬実験から量子コンピュータのレーザー校正までを扱います。起源は Anthropic と HHMI Janelia。新モデルではありません。モデル非依存のドライバと、MCP を共通バスにしたハーネス面です。開源の前に、物理安全の評価と運用の型をパートナーと作ります。

OpenAI は 8/27-28 に新モデルも新 API も出していません。教育やブラジルの投稿は、今日の主題を動かしません。X bookmarks は今ラン 0。追加の一行だけ置きます。科学者向け Team plan は 1万席、Standard 無料、Premium 月 15 ドル、生物は当面 Opus 級、Fable はプロの生物・創薬を遮断します。Claude Console では personal key と service account key が作れ、アカウントを外すとキーも止まります。Cowork 内蔵ブラウザ（8/26）は、デスクトップ側パネルで Claude 自身のブラウザを開き、移動・読み取り・クリック・入力します。拡張は不要です。ユーザーのタブ/ブックマーク/パスワードは見ません。Cookie はサイト単位（macOS は Chrome/Edge/Firefox、Windows/Linux は Firefox）。銀行/メール/SSO は選ばない限り外します。今週 Pro/Max/Team のデスクトップへ（macOS/Windows/Linux beta）。Enterprise は Organization settings → Cowork → Built-in browser で今すぐ有効化でき、届いたら既定オンです。Web/スマホはデスクトップが開いていれば駆動でき、それ以外は Claude in Chrome。新モデルではなく runtime/tool 面です。主題はハーネスの境界です。

五次元に、生まれ場所と接触面が入る

KBはハーネスを五つに置きます。案内、検証、継続、自律の制限、役割分かです。性能の差分をモデル名ではなく周辺の層で比べられます。層を混ぜると、誰が何を編集してよいかが消えます。新しい製品面は、新しいモデルではなく、この五つのどれかが伸びた合図になります。

昨日のゲート地図は「赤なら止める」層でした。今日の landscape は、その層を含む地図全体です。Cursor の Origin scratch は、継続面が GitHub 履歴を前提にしなくなった話です。MHS は、装置特性タグ、リアルタイム監視、安全限界を実験台に載せた話です。同じ「ハーネスが伸びた」でも、伸びる軸が違います。

Git を捨てる話ではない

Start from scratch は「リポジトリが無い」ではありません。プロンプトの時点で、裏に Origin repo が立ちます。気に入ったあと Create repo を押すと、足場付きの箱が残ります。継続面は消えません。所属先の SCM が、最初の一歩の外側に下がります。

進捗と履歴は、GitHub の PR 履歴である必要がなくなります。代わりに Origin が、セッションをまたぐ成果物の箱になります。Fowler の語彙では、ガイド（プロンプトと計画）が、センサ（コミット履歴）より先に走ります。センサは後から、好きなときに箱へ固定されます。

「SCM 不要」を「履歴不要」と読むと、軸が消えます。最初に要らなくなったのは、第三者 SCM の認証と、空のリモートを先に作る手続きです。ハーネスが GitHub を離れる、とは、コードの生まれ場所が、接続済みリモートから、プロンプト可能な箱へ移る話です。

緑の第一面が、Checks より前に立つ

クラウドエージェントの環境はブラウザへ届きます。live preview はセンサです。Vercel の URL は、さらに外側の公開センサです。どちらも Create repo の前に触れます。検証の第一面が、リモートの PR ではなく、エージェントがいま動かしている環境そのものになります。

代償もあります。publish は Vercel に依存します。Preview が緑でも、箱がまだ private Origin のままだと、レビュー役が入れる場所がありません。見られる面がブラウザと Vercel に先に立つなら、GitHub の Checks は後段のゲートになります。順番を混ぜると、何が正式な検証かが消えます。

MHS は新モデルではない

MHS は、装置ごとの特注統合を標準ドライバに畳みます。read と write のような命令、標準形式の発見、自然言語の特性タグ。ドライバは、測れること、変えられること、強制される安全限界を含む参照ファイルを自動で作ります。これが行動前の案内になります。

制御の口は MCP、CLI、code-file の三つです。長い作業は、ドライバ命令をファイルに連ね、装置側で確定的に走らせます。Anthropic は、Claude がレーザーを調整し、カメラで見て、学習をスクリプトに固めた例を書いています。探索は推論、繰り返しはファイルです。伸びたのはモデルではなく、装置を発見し、限界をファイルにし、三つの口で操る層です。

Genentech、ワシントン大学、CMU、Janelia、QuEra の初期例は、ラボと製造に寄っています。QuEra は量子マシン内レーザーの lock を、介入なしで 99.3% 回復する制御を書きました。本文はモデル非依存で、どのエージェントハーネスも MCP などの標準プロトコルで触れる、と書きます。Janelia 起源の共有メモリ辞書が、AI を載せるバスになった経緯も、同じ層の話です。

バスの両端と、開源前の限界

今日の二本は、MCP という共通バスの両端が同時に伸びます。一端は Origin とブラウザと Vercel。もう一端は顕微鏡と分注機とアームの read / write です。口が三つあるのは、対話で探る速度と、装置が自分で走る速度を分けるためです。バスが届く範囲が爆破半径になります。限界はモデルの慎重さではなく、ドライバが強制する値です。

Genentech の泡の例が、この層を具体にします。Claude は泡立ちをソフトウェアバグと読み、物理の失敗だと専門家に教えられるまで戻りませんでした。空間と物理の推論には、まだ専門家の監督が要ります。MCP で口が揃っても、センサの解釈は推論的なまま残ります。

MHS は研究プレビューです。開源の前に、パートナーと安全評価と運用の型を作ります。プログラムインタフェースの無い装置はまだ対象外です。科学者向け 1万席と Console のキー種別は、identity の棚です。装置バスの開閉とは別記録にします。OpenAI が静かなのはモデル面です。ハーネス面は、生まれ場所と接触面で同時に動いています。

よい読みは、MHS を新 Claude モデルだと思わないことである。コードの箱を Origin と名指し、装置の口を MCP / CLI / code-file と名指し、安全限界をドライバの参照ファイルに残す。席とキーは identity の棚に残す。Git を捨てる話にも、宇宙発射の話にもしない。
